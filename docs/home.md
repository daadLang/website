# دروس لغة ض

<div dir="rtl">

## ما هي لغة ض؟

**ض** هي لغة برمجة عربية حديثة مصممة لتكون سهلة التعلم وقوية في نفس الوقت.

- **عربية بالكامل**: جميع الكلمات المفتاحية والدوال المدمجة باللغة العربية
- **بسيطة وواضحة**: بناء الجملة يشبه Python مما يجعلها سهلة للمبتدئين
- **ديناميكية**: لا حاجة للتصريح عن أنواع البيانات
- **قوية**: تدعم البرمجة الكائنية، القوائم، القواميس، والمزيد

---

## لماذا تتعلم لغة ض؟

### سهلة التعلم

لغة ض مصممة خصيصاً للمبرمجين العرب، مما يجعل تعلم البرمجة أسهل وأكثر طبيعية.

### قوية ومرنة

على الرغم من بساطتها، فإن ض توفر مزايا متقدمة مثل الدوال، الحلقات، والبرمجة الكائنية.

### عربية أصيلة

تكتب برامجك بالعربية من البداية للنهاية، مما يسهل الفهم والتعلم.

## مثال سريع

```daad
# برنامج بسيط للترحيب
اسم = ادخل("ما اسمك؟ ")
اطبع("مرحباً " + اسم + "!")

# حساب مجموع الأرقام
دالة مجموع(أ، ب):
    ارجع أ + ب

نتيجة = مجموع(10، 20)
اطبع("المجموع: " + نص(نتيجة))
```

**النتيجة:**
```
ما اسمك؟ أحمد
مرحباً أحمد!
المجموع: 30
```
