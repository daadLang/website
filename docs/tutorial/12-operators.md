# المعاملات في لغة ض

<div dir="rtl">

## المعاملات الحسابية

| المعامل | الوصف | مثال |
|---------|-------|------|
| `+` | جمع | `5 + 3 = 8` |
| `-` | طرح | `5 - 3 = 2` |
| `*` | ضرب | `5 * 3 = 15` |
| `/` | قسمة | `10 / 3 = 3.33` |
| `//` | قسمة صحيحة | `10 // 3 = 3` |
| `%` | باقي القسمة | `10 % 3 = 1` |
| `**` | أس | `2 ** 3 = 8` |

## معاملات المقارنة

| المعامل | الوصف |
|---------|-------|
| `==` | يساوي |
| `!=` | لا يساوي |
| `<` | أصغر من |
| `>` | أكبر من |
| `<=` | أصغر أو يساوي |
| `>=` | أكبر أو يساوي |
| `في` | عضو في |
| `ليس في` | ليس عضواً في |

## المعاملات المنطقية

```daad
# و (AND)
نتيجة = صحيح و صحيح    # صحيح
نتيجة = صحيح و خطأ      # خطأ

# أو (OR)
نتيجة = صحيح أو خطأ     # صحيح
نتيجة = خطأ أو خطأ      # خطأ

# ليس (NOT)
نتيجة = ليس صحيح        # خطأ
نتيجة = ليس خطأ         # صحيح
```

## معاملات الإسناد

```daad
س = 10
س += 5    # س = س + 5
س -= 3    # س = س - 3
س *= 2    # س = س * 2
س /= 4    # س = س / 4
```

## معاملات البتات (Bitwise)

```daad
أ = 5 & 3      # AND
ب = 5 | 3      # OR
ج = 5 ^ 3      # XOR
د = ~5         # NOT
هـ = 2 << 3     # left shift
و = 16 >> 2    # right shift
```
