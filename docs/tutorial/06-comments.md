# التعليقات في لغة ض

<div dir="rtl">

## ما هي التعليقات؟

التعليقات هي نصوص توضيحية في الكود **لا يتم تنفيذها**. تستخدم لـ:
- شرح الكود
- توضيح الخوارزميات
- تعطيل أكواد مؤقتاً
- توثيق البرنامج

---

## التعليقات من سطر واحد

تبدأ بعلامة `#`:

```daad
# هذا تعليق من سطر واحد
اطبع("مرحباً")  # تعليق في نهاية السطر
```

---

## أمثلة على التعليقات

### شرح المتغيرات

```daad
# اسم الطالب
اسم = "أحمد"

# عمر الطالب بالسنوات
عمر = 20

# معدل الطالب التراكمي
المعدل = 4.5
```

### شرح العمليات

```daad
# حساب مساحة المستطيل
الطول = 10
العرض = 5
المساحة = الطول * العرض  # الطول × العرض
```

### توثيق الدوال

```daad
# دالة لحساب مربع العدد
# المعامل: رقم - العدد المراد تربيعه
# الإرجاع: مربع العدد
دالة مربع(رقم):
    ارجع رقم * رقم
```

---

## تعطيل الأكواد

يمكن استخدام التعليقات لتعطيل أكواد مؤقتاً:

```daad
# اطبع("هذا السطر معطل")
اطبع("هذا السطر يعمل")
# اطبع("هذا أيضاً معطل")
```

## أفضل الممارسات

### 1. اكتب تعليقات واضحة

```daad
# جيد
# حساب متوسط الدرجات
مجموع = 0
لكل درجة في الدرجات:
    مجموع += درجة
متوسط = مجموع / طول(الدرجات)

# سيء
# حلقة
لكل د في در:
    م += د
```

### 2. لا تكثر من التعليقات الواضحة

```daad
# سيء - واضح بدون تعليق
س = 10  # إسناد القيمة 10 للمتغير س

# جيد - التعليق يضيف معلومة
سعر_الوحدة = 10  # بالريال السعودي
```

### 3. حافظ على التعليقات محدثة

```daad
# جيد
# حساب الضريبة (15%)
الضريبة = السعر * 0.15

# سيء - التعليق قديم
# حساب الضريبة (10%)
الضريبة = السعر * 0.15  # التعليق لا يطابق الكود!
```

## أمثلة عملية

### برنامج حساب الفاتورة

```daad
# برنامج حساب فاتورة المشتريات
# الإصدار 1.0

# قراءة السعر الأساسي
السعر_الأساسي = عشري(ادخل("أدخل السعر: "))

# حساب الضريبة (15%)
الضريبة = السعر_الأساسي * 0.15

# حساب الإجمالي
الإجمالي = السعر_الأساسي + الضريبة

# عرض النتائج
اطبع("السعر الأساسي: " + نص(السعر_الأساسي))
اطبع("الضريبة (15%): " + نص(الضريبة))
اطبع("الإجمالي: " + نص(الإجمالي))
```

---

## نصائح مهمة

1. **استخدم اللغة العربية**: اكتب التعليقات بالعربية لتوافق اللغة
2. **كن موجزاً**: اشرح "لماذا" وليس "ماذا"
3. **حدّث التعليقات**: عند تغيير الكود، حدّث التعليقات
4. **لا تعلق الواضح**: الكود الجيد يشرح نفسه
