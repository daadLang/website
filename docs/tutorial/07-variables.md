# المتغيرات في لغة ض

<div dir="rtl">

## ما هو المتغير؟

المتغير هو اسم يُستخدم لتخزين قيمة في الذاكرة. يمكن تغيير قيمته أثناء تنفيذ البرنامج.

```ض
اسم = "أحمد"
عمر = 25
```

---

## إنشاء المتغيرات

### الإسناد البسيط

```ض
س = 10
ص = "مرحباً"
ع = 3.14
```

### إسناد متعدد

```ض
# إسناد نفس القيمة لعدة متغيرات
س = ص = ع = 0

# إسناد قيم مختلفة
أ، ب، ج = 1، 2، 3
```

---

## قواعد تسمية المتغيرات

### أسماء صحيحة

```ض
اسم = "أحمد"
الاسم_الكامل = "أحمد محمد"
عمر1 = 25
_متغير = 10
اسم123 = "قيمة"
```

### أسماء خاطئة

```ض
1اسم = "أحمد"        # لا يبدأ برقم
اسم-العائلة = "محمد" # لا يحتوي شرطة
اسم العائلة = "علي"  # لا مسافات
إذا = 10              # كلمة محجوزة
```

### القواعد

1. يبدأ بحرف (عربي/إنجليزي) أو `_`
2. يحتوي على حروف، أرقام، و `_`
3. حساس لحالة الأحرف
4. لا يستخدم كلمات محجوزة

## أنواع المتغيرات

### أرقام صحيحة

```ض
عمر = 25
السنة = 2024
درجة_الحرارة = -5
```

### أرقام عشرية

```ض
السعر = 99.99
المعدل = 4.75
pi = 3.14159
```

### نصوص

```ض
اسم = "أحمد"
المدينة = 'الرياض'
رسالة = """هذا نص
متعدد الأسطر"""
```

### قيم منطقية

```ض
متزوج = صحيح
موظف = خطأ
قيمة_فارغة = عدم
```

## تغيير قيم المتغيرات

```ض
# إنشاء متغير
س = 10
اطبع(س)  # 10

# تغيير القيمة
س = 20
اطبع(س)  # 20

# تغيير النوع
س = "نص"
اطبع(س)  # نص
```

## العمليات على المتغيرات

### العمليات الحسابية

```ض
س = 10
ص = 5

مجموع = س + ص       # 15
فرق = س - ص          # 5
ضرب = س * ص          # 50
قسمة = س / ص         # 2
```

### الإسناد المعزز

```ض
عداد = 0
عداد += 1    # عداد = عداد + 1
عداد -= 1    # عداد = عداد - 1
عداد *= 2    # عداد = عداد * 2
عداد /= 2    # عداد = عداد / 2
```

## نطاق المتغيرات

### متغيرات محلية

```ض
دالة تحية():
    اسم = "أحمد"  # متغير محلي
    اطبع(اسم)

تحية()
# اطبع(اسم)  # خطأ: اسم غير معرف خارج الدالة
```

### متغيرات عامة

```ض
العداد = 0  # متغير عام

دالة زيادة():
    العداد += 1  # استخدام المتغير العام

زيادة()
اطبع(العداد)  # 1
```

## أمثلة عملية

### مثال 1: حساب المساحة

```ض
# إدخال البيانات
الطول = عشري(ادخل("أدخل الطول: "))
العرض = عشري(ادخل("أدخل العرض: "))

# الحسابات
المساحة = الطول * العرض
المحيط = 2 * (الطول + العرض)

# النتائج
اطبع("المساحة: " + نص(المساحة))
اطبع("المحيط: " + نص(المحيط))
```

### مثال 2: تبديل قيم متغيرين

```ض
أ = 10
ب = 20

اطبع("قبل التبديل: أ=" + نص(أ) + "، ب=" + نص(ب))

# التبديل
مؤقت = أ
أ = ب
ب = مؤقت

اطبع("بعد التبديل: أ=" + نص(أ) + "، ب=" + نص(ب))
```

## أفضل الممارسات

### 1. استخدم أسماء وصفية

```ض
# جيد
اسم_الطالب = "أحمد"
درجة_الرياضيات = 95

# سيء
س = "أحمد"
د = 95
```

### 2. كن متسقاً في التسمية

```ض
# استخدم نمط واحد
اسم_الطالب = "أحمد"
عمر_الطالب = 20
درجة_الطالب = 95
```

### 3. تجنب الأسماء المضللة

```ض
# سيء
عدد_الطلاب = "أحمد"  # يجب أن يكون رقماً!

# جيد
عدد_الطلاب = 30
اسم_الطالب = "أحمد"
```
