# حلقة لكل في لغة ض

<div dir="rtl">

## بناء الجملة

```ض
لكل متغير في مجموعة:
    # كود يتكرر لكل عنصر
```

## التكرار على القوائم

```ض
فواكه = ["تفاح"، "موز"، "برتقال"]

لكل فاكهة في فواكه:
    اطبع(فاكهة)
```

## استخدام مدى()

```ض
# من 0 إلى 4
لكل ع في مدى(5):
    اطبع(ع)

# من 1 إلى 10
لكل ع في مدى(1، 11):
    اطبع(ع)

# بخطوات معينة
لكل ع في مدى(0، 10، 2):
    اطبع(ع)  # 0، 2، 4، 6، 8
```

## حلقة كرر (سكر نحوي)

```ض
# تكرار 5 مرات
كرر 5 مرات:
    اطبع("مرحباً")

# مكافئ لـ:
لكل _ في مدى(5):
    اطبع("مرحباً")
```

## التكرار على القواميس

```ض
طالب = {"اسم": "أحمد"، "عمر": 20، "معدل": 4.5}

لكل مفتاح في طالب:
    اطبع(مفتاح + ": " + نص(طالب[مفتاح]))
```

## اخرج و تابع

```ض
لكل عدد في مدى(10):
    إذا عدد == 5:
        اخرج  # توقف عند 5
    
    إذا عدد % 2 == 0:
        تابع  # تخطي الأرقام الزوجية
    
    اطبع(عدد)  # 1، 3
```

## أمثلة عملية

### مثال 1: جدول الضرب

```ض
رقم = عدد(ادخل("أدخل رقماً: "))

اطبع("جدول الضرب للعدد " + نص(رقم))
لكل ع في مدى(1، 11):
    اطبع(نص(رقم) + " × " + نص(ع) + " = " + نص(رقم * ع))
```

### مثال 2: حساب المتوسط

```ض
درجات = [85، 90، 78، 92، 88]

مجموع = 0
لكل درجة في درجات:
    مجموع += درجة

متوسط = مجموع / طول(درجات)
اطبع("المتوسط: " + نص(متوسط))
```

### مثال 3: رسم مثلث

```ض
ارتفاع = 5

لكل س في مدى(1، ارتفاع + 1):
    اطبع("*" * س)
```
