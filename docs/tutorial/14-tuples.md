# المجموعات الثنائية في لغة ض

<div dir="rtl">

## ما هي المجموعة الثنائية؟

مجموعة **غير قابلة للتعديل** من العناصر.

```daad
# إنشاء مجموعة ثنائية
نقطة = (10، 20)
ألوان = ("أحمر"، "أخضر"، "أزرق")
```

## الوصول للعناصر

```daad
نقطة = (10، 20، 30)
اطبع(نقطة[0])    # 10
اطبع(نقطة[-1])   # 30
```

## الفرق بين القوائم والمجموعات الثنائية

```daad
# قائمة - قابلة للتعديل
قائمة = [1، 2، 3]
قائمة[0] = 10  # يعمل

# مجموعة ثنائية - غير قابلة للتعديل
ثنائي = (1، 2، 3)
# ثنائي[0] = 10  # خطأ!
```

## الاستخدامات

```daad
# إحداثيات
موقع = (24.7136، 46.6753)  # الرياض

# تواريخ
تاريخ = (2024، 1، 29)

# قيم ثابتة
أيام_الأسبوع = ("السبت"، "الأحد"، "الاثنين"، "الثلاثاء"، "الأربعاء"، "الخميس"، "الجمعة")
```
