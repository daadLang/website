# القيم المنطقية في لغة ض

<div dir="rtl">

## القيم المنطقية

قيمتان فقط:
- `صحيح` (True)
- `خطأ` (False)

```daad
نشط = صحيح
متزوج = خطأ
موظف = صحيح
```

## العمليات المنطقية

```daad
# و (AND)
إذا العمر >= 18 و مواطن:
    اطبع("يمكنه التصويت")

# أو (OR)
إذا طالب أو موظف:
    اطبع("لديه هوية")

# ليس (NOT)
إذا ليس مسجل:
    اطبع("يجب التسجيل")
```

## التحويل لمنطقي

```daad
# القيم الصحيحة
صحيح إذا كان: أي رقم غير صفر، أي نص غير فارغ، قوائم غير فارغة

# القيم الخاطئة
خطأ إذا كان: صفر، نص فارغ ""، قوائم فارغة []، عدم
```
