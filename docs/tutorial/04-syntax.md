# بناء الجملة في لغة ض

<div dir="rtl">

## القواعد الأساسية

### 1. المسافات البادئة (Indentation)

المسافات البادئة **إلزامية** في لغة ض لتحديد كتل الكود:

```daad
# صحيح
إذا س > 0:
    اطبع("موجب")
    اطبع("أكبر من صفر")

# خطأ - لا توجد مسافات بادئة
إذا س > 0:
اطبع("موجب")
```

**القاعدة:**
- استخدم **4 مسافات** أو **Tab واحد**
- كن ثابتاً في الاختيار (لا تخلط بينهما)

### 2. التعليقات

التعليقات تبدأ بـ `#` ويتم تجاهلها عند التنفيذ:

```daad
# هذا تعليق من سطر واحد
اطبع("مرحباً")  # تعليق في نهاية السطر

# يمكن استخدام عدة أسطر للتعليقات
# سطر 1
# سطر 2
# سطر 3
```

**ملاحظة:** لا توجد تعليقات متعددة الأسطر (`""" """`) حالياً.

### 3. الأسطر الجديدة

كل جملة في سطر منفصل:

```daad
س = 10
ص = 20
ع = 30
```

لا حاجة لفاصلة منقوطة (`;`) في نهاية كل سطر.

## المتغيرات

### إنشاء المتغيرات

```daad
# متغيرات بسيطة
اسم = "أحمد"
عمر = 25
الراتب = 5000.50
متزوج = صحيح
```

### قواعد تسمية المتغيرات

 **مسموح:**
```daad
اسم = "أحمد"
الاسم_الكامل = "أحمد محمد"
عمر1 = 25
_متغير = 10
```

 **غير مسموح:**
```daad
1عمر = 25        # لا يبدأ برقم
اسم-العائلة = "أحمد"  # لا يحتوي على شرطة
إذا = 10         # لا يستخدم كلمة مفتاحية
```

**القواعد:**
1. يجب أن يبدأ بحرف (عربي أو إنجليزي) أو `_`
2. يمكن أن يحتوي على حروف، أرقام، و `_`
3. **حساس لحالة الأحرف**: `اسم` ≠ `الاسم`
4. لا يمكن استخدام الكلمات المفتاحية

## الكلمات المفتاحية

الكلمات المحجوزة في لغة ض:

| الكلمة | الاستخدام | الكلمة | الاستخدام |
|--------|-----------|--------|-----------|
| `إذا` / `اذا` | شرط if | `وإذا` / `واذا` | شرط elif |
| `وإلا` / `والا` | شرط else | `طالما` | حلقة while |
| `لكل` | حلقة for | `في` | عضوية in |
| `دالة` | تعريف دالة | `ارجع` / `أرجع` | إرجاع قيمة |
| `اخرج` | خروج من حلقة | `تابع` | استمرار حلقة |
| `كرر` | حلقة تكرار | `مرات` / `مرة` | مع كرر |
| `و` | and منطقي | `أو` / `او` | or منطقي |
| `ليس` / `لا` | not منطقي | `صحيح` | True |
| `خطأ` | False | `عدم` | None |
| `صنف` | تعريف صنف | `ذاتي` | self |

## بناء الجملة الأساسي

### 1. الطباعة

```daad
اطبع("مرحباً بالعالم")
اطبع("العدد:", 42)
اطبع("الاسم:", اسم, "العمر:", عمر)
```

### 2. الإسناد

```daad
# إسناد بسيط
س = 10

# إسناد متسلسل
س = ص = ع = 0

# إسناد معزز
س += 5   # س = س + 5
ص -= 3   # ص = ص - 3
ع *= 2   # ع = ع * 2
```

### 3. الإدخال

```daad
# قراءة نص
اسم = ادخل("أدخل اسمك: ")

# قراءة رقم
عمر = عدد(ادخل("أدخل عمرك: "))

# قراءة رقم عشري
السعر = عشري(ادخل("أدخل السعر: "))
```

## العمليات الأساسية

### عمليات حسابية

```daad
# جمع
نتيجة = 10 + 5      # 15

# طرح
نتيجة = 10 - 5      # 5

# ضرب
نتيجة = 10 * 5      # 50

# قسمة
نتيجة = 10 / 5      # 2.0

# قسمة صحيحة
نتيجة = 10 // 3     # 3

# باقي القسمة
نتيجة = 10 % 3      # 1

# أس
نتيجة = 2 ** 3      # 8
```

### عمليات مقارنة

```daad
# المساواة
س == ص

# عدم المساواة
س != ص

# أكبر من
س > ص

# أصغر من
س < ص

# أكبر من أو يساوي
س >= ص

# أصغر من أو يساوي
س <= ص
```

### عمليات منطقية

```daad
# و (AND)
إذا س > 0 و ص > 0:
    اطبع("كلاهما موجب")

# أو (OR)
إذا س == 0 أو ص == 0:
    اطبع("أحدهما صفر")

# ليس (NOT)
إذا ليس متصل:
    اطبع("غير متصل")
```

## الجمل الشرطية

### if بسيط

```daad
إذا العمر >= 18:
    اطبع("بالغ")
```

### if-else

```daad
إذا العمر >= 18:
    اطبع("بالغ")
وإلا:
    اطبع("قاصر")
```

### if-elif-else

```daad
إذا الدرجة >= 90:
    اطبع("ممتاز")
وإذا الدرجة >= 80:
    اطبع("جيد جداً")
وإذا الدرجة >= 70:
    اطبع("جيد")
وإذا الدرجة >= 60:
    اطبع("مقبول")
وإلا:
    اطبع("راسب")
```

## الحلقات

### حلقة while

```daad
عداد = 0
طالما عداد < 5:
    اطبع(عداد)
    عداد += 1
```

### حلقة for

```daad
# التكرار على قائمة
أرقام = [1، 2، 3، 4، 5]
لكل رقم في أرقام:
    اطبع(رقم)

# استخدام مدى
لكل ع في مدى(10):
    اطبع(ع)  # 0 إلى 9
```

### حلقة التكرار (كرر)

```daad
# تكرار 5 مرات
كرر 5 مرات:
    اطبع("مرحباً")
```

## الدوال

### تعريف دالة بسيطة

```daad
دالة تحية():
    اطبع("مرحباً!")

# استدعاء الدالة
تحية()
```

### دالة مع معاملات

```daad
دالة جمع(أ، ب):
    ارجع أ + ب

نتيجة = جمع(10، 20)
اطبع(نتيجة)  # 30
```

### دالة مع قيم افتراضية

```daad
دالة تحية(اسم = "ضيف"):
    اطبع("مرحباً " + اسم)

تحية()          # مرحباً ضيف
تحية("أحمد")    # مرحباً أحمد
```

## القوائم والمجموعات

### قائمة

```daad
# إنشاء قائمة
أرقام = [1، 2، 3، 4، 5]

# الوصول للعناصر
اطبع(أرقام[0])    # 1
اطبع(أرقام[-1])   # 5

# تعديل عنصر
أرقام[0] = 10
```

### قاموس

```daad
# إنشاء قاموس
شخص = {"اسم": "أحمد"، "عمر": 25}

# الوصول للقيم
اطبع(شخص["اسم"])  # أحمد

# إضافة عنصر جديد
شخص["مدينة"] = "الرياض"
```

### مجموعة ثنائية (Tuple)

```daad
# إنشاء مجموعة ثنائية (غير قابلة للتعديل)
نقطة = (10، 20)
اطبع(نقطة[0])  # 10
```

## الأصناف (Classes)
 
:::warning
ميزة الأصناف لا تزال قيد التطوير. بعض أجزاء تصميم الأصناف والسلوك قد تتغير في الإصدارات القادمة.
:::

```daad
صنف شخص:
    دالة __بناء__(ذاتي، اسم، عمر):
        ذاتي.اسم = اسم
        ذاتي.عمر = عمر
    
    دالة تحية(ذاتي):
        اطبع("مرحباً، أنا " + ذاتي.اسم)

# إنشاء كائن
أحمد = شخص("أحمد"، 25)
أحمد.تحية()  # مرحباً، أنا أحمد
```

## أفضل الممارسات

### 1. استخدم أسماء واضحة

```daad
# جيد
اسم_الطالب = "أحمد"
درجة_الرياضيات = 95

# سيء
س = "أحمد"
د = 95
```

### 2. أضف تعليقات مفيدة

```daad
# حساب متوسط الدرجات
مجموع = 0
لكل درجة في الدرجات:
    مجموع += درجة
متوسط = مجموع / طول(الدرجات)
```

### 3. حافظ على المسافات البادئة

```daad
# استخدم 4 مسافات دائماً
إذا شرط:
    جملة1
    جملة2
    إذا شرط_آخر:
        جملة3
```

### 4. اجعل الدوال قصيرة ومحددة

```daad
# دالة تقوم بمهمة واحدة
دالة حساب_المربع(رقم):
    ارجع رقم * رقم
```

## الأخطاء الشائعة

### خطأ في المسافات البادئة

```daad
#  خطأ
إذا س > 0:
اطبع("موجب")

#  صحيح
إذا س > 0:
    اطبع("موجب")
```

### نسيان النقطتين

```daad
#  خطأ
دالة مجموع(أ، ب)
    ارجع أ + ب

#  صحيح
دالة مجموع(أ، ب):
    ارجع أ + ب
```

### خلط الكلمات المفتاحية

```daad
#  خطأ - استخدام كلمات إنجليزية
if س > 0:
    print("موجب")

#  صحيح - استخدام كلمات عربية
إذا س > 0:
    اطبع("موجب")
```
